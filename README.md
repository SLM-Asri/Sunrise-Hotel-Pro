<h1>🌅 Sunrise Hotel</h1>

<h3>“A modern hotel website built with HTML, CSS, and JavaScript.”</h3>
<p> 
  Sunrise Hotel is a front‑end web project built with HTML, CSS, and JavaScript. It showcases a modern hotel website design with 
  interactive features, responsive layouts, and a clean user experience. The project is ideal for demonstrating core web 
  development skills and can be extended into a full hotel management system.
</p> 
<h4>✨ Features</h4>
  <ul>
    <li>Elegant homepage with hotel branding</li>
    <li>Interactive navigation and responsive design</li>
    <li>Contact form for inquiries</li>
    <li>Room showcase with images and descriptions</li>
    <li>Smooth animations and transitions using JavaScript</li>
  </ul>


<h4>🛠️ Tech Stack</h4>
<ul>
    <li>HTML – structure and content</li>
    <li>CSS – styling and responsive layouts</li>
    <li>JavaScript – interactivity and dynamic behavior</li>
  </ul>










<h4>🎯 Purpose</h4>


<p>
The goal of Sunrise Hotel is to provide a professional, visually appealing hotel website that highlights services and makes it easy for guests to connect with the hotel online.</p>
